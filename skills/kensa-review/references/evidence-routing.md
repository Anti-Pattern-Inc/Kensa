# Evidence routing

How each of the 57 questions and 307 best practices is filled in, by route.
**A = AWS (live environment, read-only) / R = repository (IaC, documents, GitHub settings and activity, CI) / I = interview (decision cards)**. The first letter is the primary route; if the primary route cannot settle an item, the next route is tried. A trailing `*` marks a **draft** route (the evidence can only show that something exists, and a person confirms it; absence is not grounds for a verdict).
The source of truth is `assets/routing.json` (per-QuestionId defaults plus per-ChoiceId overrides). A ChoiceId that is unknown (another lens, or an update) falls back to its QuestionId default, and failing that to interview. Classify it with `route-unknown` / `route-apply`, which registers it in `.kensa/routing.local.json`.
This document is generated by `scripts/gen_routing_doc.py`.

`areas` is the join key to the AWS / repository checks (`aws-readonly-checks.md` / `repo-signals.md`). Use it as in `items --area kms`.
